## ✨ About

**Dar Al Muneerah** is an Islamic learning platform at the International Islamic University, Islamabad. It presents the institute's programs and teachers, lets students and instructors apply online, and gives administrators a secure dashboard to review applications and manage content — with full **Arabic (RTL)** and **English (LTR)** support.

## 🚀 Features

- 🌍 **Bilingual & RTL** — complete Arabic / English interface with true right-to-left mirroring
- 📚 **Programs & Courses** — Tajweed, Hifz ul Qur'an, Understanding Qur'an, Hifz ul Ahadees, Aqeedah & more
- 📝 **Student Registration** — guided multi-step form with document uploads
- 👩‍🏫 **Instructor Applications** — dedicated application flow
- 🖼️ **Gallery & Teachers** — managed from the admin panel
- 📢 **News & Announcements** — bilingual, managed from the dashboard
- 🔐 **Secure Admin Dashboard** — authentication, application review, analytics & PDF export
- 📱 **Responsive Design** — polished on mobile, tablet, and desktop
