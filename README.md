## ✨ Overview

**Dar Al‑Munira** is a modern, fully responsive web platform built for the Islamic education
programs at the International Islamic University Islamabad. It presents the institute's
courses and teachers, lets students and instructors apply online, and gives administrators a
secure dashboard to review applications, manage content, and track activity — all with
first‑class support for both **Arabic (RTL)** and **English (LTR)**.

> 🌐 **Visit the live website:** **https://darmunira.netlify.app/**

---

## 🚀 Key Features

| Area | What it does |
| --- | --- |
| 🌍 **Bilingual & RTL** | Full Arabic / English interface with proper right‑to‑left layout |
| 📚 **Programs & Courses** | Tajweed, Hifz ul Qur'an, Understanding Qur'an, Arabic Institute, Fiqh, Aqeedah, and more |
| 📝 **Student Registration** | Guided multi‑step form with a Juz' picker for Qur'an memorization |
| 👩‍🏫 **Instructor Applications** | Dedicated application flow with document upload |
| 🖼️ **Gallery** | Managed image gallery for the institute |
| 👥 **Teachers Directory** | Public teacher profiles managed from the admin panel |
| 📢 **Announcements & News** | Post and manage institute updates |
| 🔐 **Secure Admin Dashboard** | Authentication, application review, analytics & charts |
| 📄 **PDF Export** | Export applications and reports to PDF |
| 📱 **Responsive Design** | Polished experience on mobile, tablet, and desktop |

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router) + React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Framer Motion animations
- **Database & ORM:** PostgreSQL / SQLite via Prisma
- **Auth:** Secure sessions with `jose` + `bcryptjs`
- **Forms & Validation:** React Hook Form + Zod
- **Charts & Reports:** Recharts + jsPDF
- **Deployment:** Netlify (primary) & Vercel (mirror)
